# Floor Estimator 3D (v0.22)

A mobile-first 3D floor estimator for a Seattle/Eastside hardwood and tile contractor (Rhino Lab brand; "VIPRO" is a temporary site name). Built with Next.js 14 static export, React Three Fiber and a tested pricing engine.

- **Start here:** [HANDOFF.md](./HANDOFF.md) covers the full spec, architecture, pricing rules, backlog and acceptance checklist.
- **Live preview (v0.22):** https://vipro-floor-3d-454rqo2dk-pcpshow1-2216s-projects.vercel.app
- **Source:** `src-v5/` (`npm ci && npm run dev`, `npm test`, `npm run build`)
- Original client brief: `docs/VIPRO_calculator_brief.md`

All prices are provisional benchmarks, not approved quotes. This repo contains no secrets.
